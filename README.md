SupportDesk

A full-stack IT support ticket management application built with Next.js.

About the Project

SupportDesk allows users to report technical problems and enables support agents to manage, assign, and resolve support tickets.

Technologies

Next.js

React

JavaScript

PostgreSQL

Authentication

Features

User registration and authentication

Role-based access control

Create and manage support tickets

Ticket assignment

Comments and conversations

Dashboard and ticket statistics

Search and filtering

Getting Started

1. Clone the repository

git clone (https://github.com/ErdemUgurlular/supportdesk)
cd supportdesk

2. Install dependencies

npm install

3. Configure environment variables

Create a .env.local file using .env.example as a template.

4. Start the development server

npm run dev

Open http://localhost:3000 in your browser.
